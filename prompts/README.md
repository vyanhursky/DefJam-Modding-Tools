# Versioned restoration instructions

The executable brief template is `defjam_tools.texture_workshop.brief()`, tested
with synthetic review/parent inputs. `rich-original-detail.txt` states the reusable
art policy. The gallery adds the selected asset/revision, region notes and owner
feedback when queueing a request. Exact prompts actually submitted to ImageGen
remain with private candidate provenance, alongside raw results and references.

Image generation runs in the authoring conversation. The tools do not call an
image API or start generation merely because a brief was queued.
