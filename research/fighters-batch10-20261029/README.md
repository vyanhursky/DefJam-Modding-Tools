XML identity, texture0 IDs, source geometry and accepted corpus hashes were
measured before editing. Method Man is already represented by Blaze. Xzibit
and Ghostface were excluded because the existing decoder rejects their index
headers; no speculative decoder changes were needed for the chosen ten.

`assemble.py` consumes a PRIVATE plan/raw PNG directory and actual geometry.
It uses existing regional detail and cloth-palette tools. Original UV layout,
likeness and source broad color/shading remain authoritative. Rich Original
Detail covers head/face/hair/headwear, skin, clothing/footwear and safe opaque
jewelry. Eye/alpha/unknown-material coverage plus one source texel is held.
Both sides of unambiguous distinct paired skin UV edges are measured/guarded;
no pilot quadrant, anatomical bounds, seam count or eye coordinates are reused.

The inspected per-fighter plan also holds mouth/teeth tiles and source glyph/
watchface/clock/emblem designs where new generated art drifted or guessed detail.
These are declared exceptions rather than claimed restored inscriptions. Cloth
matching runs last, including Ice-T cloth1, then exact source holds/alpha/seam
cores are restored. The script refuses an existing stage and records every
processor/input/output hash and material-component coverage/palette diagnostics.
