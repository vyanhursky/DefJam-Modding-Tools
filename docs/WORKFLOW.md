# Restore, review, export

1. Resume the existing corpus/workspace using local.json and `defjam-tools serve`.
2. Choose a category/fighter and inspect the original atlas and faithful HD.
3. Save regional notes and references. Ask ImageGen for Rich Original Detail;
   preserve UVs, likeness, alpha and original composition. Face/head/hair edits
   are owner-authorized for the fighter pilot; otherwise honor its edit scope. Exact submission
   and raw output must remain attached to the imported candidate.
4. Import a new immutable revision using the gallery or `defjam-tools workshop
   import`. Use protected-region/parent-bound assembly for precise revisions.
5. Compare at fixed atlas zoom or in the 3D viewer. Save notes/flags on the exact
   revision. The original is the authority for placement and shapes. Request
   targeted edits instead of cascading a redesigned candidate as the sole input.
6. Approve the exact reviewed revision after checking likeness and texture channels. Export
   selected sparse schema 1 packs; test locally through the recomp loader.
   Mark in-game verification only after an actual game test.

All review decisions, exact prompts, images and exports remain in the private
workspace. Back it up with the matching corpus. The source repository retains
templates, tooling, tests and technical research, not those assets.

Current pilot: Blaze, Nyne, Trejo, Redman, Henry Rollins. Nyne/Trejo v3 and
Redman/Blaze v4 are visually accepted, as are Rollins' head/hair/clothes/boots.
Rollins' skin/tattoos remain incomplete after the owner-requested retry was blocked.
See [fighter restoration calibration](fighter-restoration.md) before extending
the batch. Static model previews are available; animation, venues and mesh
reimport are future work.
